///////////////////Manage and Configure Virtual Machines /////

Linux (QEMU-KVM) - Quick Emulator Kernel-based Virtual Machine

Virsh - Manage Virtual Machines from the CMD

>sudo apt install virt-manager  Note :usully we need Linux UI for use it

>vim testmachine.xml - create a file where we are going to add content for creationg virtual machine (look the xml in the internet)

>virsh define testmachine.xml - will create the VM from this xml exctractions

>virsh help - for more commands

>virsh list  - to see active domains(machines)

>virsh list --all  - to see all of them even those which are not active

>virsh start testmachine - will start the machine

>virsh reboot testmachine

>virsh destroy testmachine - power off

>virsh undefine testmachine  - delete testmachine

>virsh help undifined - to check what undefined does

>virsh undefine --remove-all-storage testmachine   - remove all the storage which machine created


Start machine manually:
>virsh define testmachine

>virsh autostart testmachine  - start machine when Linux BOOTs

>virsh autostart --disable testmachine   - disable start on the Linux boot

>virsh dominfo testmachine   - to explore machine's resources  (CPU,Memory)

>virsh set - to modify vm (like add more CPU)

>virsh help setvcpus   - check the options

>virsh setvcpu testmachine 2 --config 

>virsh setvcpu testmachine 2 --config --maximum   - set maximum cpu 2 .Will not chage on the fly .Need stop the machine and start again
>virsh setvcpu testmachine 2 --config 

>virsh destroy testmachine

>virsh start testmachine

check if we have now 2 CPU:

>virsh dominfo testmachine  - we will see 2 CPU now


To change Memory size:
>virsh setmaxmem testmachine 2048M --config
>virsh setmem testmachine 2048M --config 
>virsh destroy testmachine
>virsh start testmachine
>virsh dominfo - now we can seee it been changed
