ubuntu.json:

  "builders": [
    {
      "type": "qemu",
      "iso_url": "ubuntu.iso",
      "iso_checksum": "none",
      "output_directory": "output-ubuntu",
      "disk_size": 20000,
      "format": "qcow2",
      "accelerator": "kvm",
      "ssh_username": "packer",
      "ssh_password": "packer",
      "ssh_timeout": "20m",
      "shutdown_command": "echo 'packer' | sudo -S shutdown -P now"
    }
  ]
}

packer build ubuntu.json

launches QEMU
automatically installs the OS
performs provisioning (Ansible, shell, cloud-init)
creates a ready-to-use qcow2 image

In short:

This is a fully CLI-based VM installation, no GUI, downloading Debian installer from the web and installing it directly — very useful for automation, servers, and DevOps workflows.

virt-install --osinfo debian12 --name debian1 --memory 1024 --vcpus 1 --disk size=10 \
--location https://deb.debian.org/debian/dists/bookworm/main/installer-amd64/ \
--graphics none --extra-args "console=ttyS0"

What it does (simple explanation)

This command creates and installs a virtual machine from the terminal using virt-install.

Breakdown:
virt-install
Tool to create VMs from CLI (part of KVM/libvirt)
--osinfo debian12
Tells it the OS is Debian 12 (optimizes settings)
--name debian1
Name of the VM
--memory 1024
1 GB RAM
--vcpus 1
1 CPU core
--disk size=10
Creates a 10 GB virtual disk
--location https://...
Uses Debian installer directly from the internet (no ISO needed)
--graphics none
No GUI → runs in terminal (headless)
--extra-args "console=ttyS0"
Redirects installer output to terminal (so you can see and interact)


In short:

This is a fully CLI-based VM installation, no GUI, downloading Debian installer from the web and installing it directly — very useful for automation, servers, and DevOps workflows.
