////////////////CSR //////////
Ceritifates Signing Request

To keep connection encrypted between user and site(production) we can not use self-sign certificate - it should be signed by AYTHORITY
then any browser can checl our certificate and see it as valid and legitimated

How the generate a PRIVATE key and CSR:

>openssl req -newkey rsa:2058 -keyout key.pem -out req.pem
Where: we want to generate a key which type will be RSA 2048 bits and save it to the key.pem and CSR save to the req.pem
And fill the Org,Country.....and password.In the end it will generate a private and encrypted key.pem and req.pem files (use >cat key.pem to see the key or CSR >cat req.pem)

In production we will send this req.pem file + check our identity and to sign in Cetificate AYTHORITY to get e certificate.
