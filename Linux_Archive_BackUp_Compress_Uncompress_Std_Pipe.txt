//////////////////////Archive file (only one file these utilities can compress) ///////

>tar --create --file archive.tar file1  OR tar cf archive.tar file1 

/////////////////////Append file to already existing tar file //////////

>tar --append --file  archive.tar  file2 OR tar rf archive.tar.file2

////////////////////create TAR from Directory ///////////

>tar --create --file archive.tar Pictures/

>tar --create --file archive.tar /home/aaron/Pictures/


////////////////////////Before extracting nice to look inside the tar, and see what we have --list //////////

>tar --list --file archive.tar OR tar tf archive.tar 

//////////////////////////Exrtract from TAR file into current directory ////////////

>tar -extract --file archive.tar OR tar xf archive.tar   (will extract the files in the current directory)


///////////////////////Extract from TAR to different directory /////////////////

tar --extract --file archive.tar --directory /tmp/ OR tar xf archive.tar -C /tmp/


///////////////////////Extract with keeping all priviligies for the files - they had before ///////////

>sudo tar --extract -file archive.tar --directory /tmp/

 //////////////////////////Backup Files to a Remote System -with native Linux tools ///////////
 
 rsync = remote syncranization .Remote server must have SSH daemon running 
 
 ////////////////////Sync Two Directories ///////
 
 rsync is a command‑line tool that efficiently synchronizes files and directories by copying only the parts that have changed, making it ideal for backups, mirroring, and transferring data locally or over SSH.
 
 > rsync -a Pictures/ dani@192.168.2.101:/home/aaron/Pictures/ 
 > rsync -a dani@192.168.2.101:/home/aaron/Pictures/ Pictures/ 
 
 will sync from the next time only delta files which were not copied 
 as well the option to sync two local directories
 > rsync -a Pictures/ Backups/Pictures/ 
 
 ////////////////Disk Imaging - (bit by bit copuing) ///////
 But before you do the image from the disk - it should be unmount - to valiudate no new data be added to the disk during we create am image !!
 
 How to checl if there a DISK or File or DIRECTORY:
 > ls - l and then see the first char( example: drwxr-xr-x  2 root root 4096 Mar 30  /etc - where if "d" - directory, "-" =- regular file, "|" - symlink, "b" - block device)disk) , "c" - character device
 
 > sudo dd if=/dev/vda of=diskimage.raw bs=1M status=progress (do not run this command in the virtual machine cause it will overwrite you virtual disk)
 
 To restore image to the disk:
 > sudo dd if=diskimage.raw of=/dev/vda bs=1M status=progress (do not run in the virtual machine - will overwrite the vm disk)
