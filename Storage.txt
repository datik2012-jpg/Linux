When we install Ubuntu - SWAP and file will be set by default

To do it manually(create a swap file) we need create a next file with binary zero filled:

sudo dd if=/dev/zero of=/swap bs=1M count=128

This creates a 128 MB swap file filled with zeros.

Here’s the meaning of each part:

sudo
Runs the command with administrator privileges.

dd
A low‑level copying tool used to write raw data to files or devices.

if=/dev/zero
if = input file

/dev/zero is a special file that outputs infinite zeros

So you’re writing zeros into the new file

of=/swap
of = output file

This creates a file named /swap in the root directory

bs=1M
Block size = 1 megabyte

Each block written is 1 MB

count=128
Write 128 blocks

128 × 1 MB = 128 MB swap file

What happens next (normally)
After creating the file, you would:

Set correct permissions

Code
sudo chmod 600 /swap  - only root user can read and write to this swap file
Format it as swap

Code
sudo mkswap /swap
Enable it

check the swap active areas again:
>sudo swapon --verbose /swap

swapon --show 

Code
sudo swapon /swap
Make it permanent in /etc/fstab

Code
/swap   none   swap   sw   0  0



Another command wil show us the progress during creation a swap file:

sudo dd if=/dev/zero of=/swap bs=1M count=2048 status=progress

-i size=512 — sets the inode size to 512 bytes (default is usually 256). Larger inodes can store more extended attributes, useful for systems with heavy metadata usage.

An inode (short for index node) is a fundamental data structure used by many Unix‑like file systems—including XFS, ext4, and others—to store metadata about a file.



Force formating :

>sudo vim /etc/fstab

/dev/vdb3    none    swap    defaults    0    0

/etc/fstab — the file that defines which disks and partitions are mounted automatically at boot, and where they’re mounted.

What it means
/dev/vdb3 — the device that will be used for swap.

none — no mount point, because swap isn’t part of the filesystem hierarchy.

swap — specifies the filesystem type as swap space.

defaults — uses standard mount options.

0 0 — disables dump and fsck checks (swap doesn’t need them).


Why it’s important
Swap acts as virtual memory, extending RAM by using disk space when physical memory runs low. It helps prevent out‑of‑memory crashes and keeps the system responsive under heavy load.

Configure the system to automatically use /dev/vdd as swap when it boots up.


For now, you do not need to reboot the system after making the required changes as this might affect the next task.

sudo dd if=/dev/vdd of=/swap bs=1M count=128 status=progress

bob@caleston-lp10 ~ ✖ sudo dd if=/dev/vdd of=/swap bs=1M count=128 status=progress
128+0 records in
128+0 records out
134217728 bytes (134 MB, 128 MiB) copied, 0.165476 s, 811 MB/s

sudo chmod 600 /swap

Format it:
bob@caleston-lp10 ~ ➜  sudo mkswap /swap
mkswap: /swap: warning: wiping old xfs signature.
Setting up swapspace version 1, size = 128 MiB (134213632 bytes)
no label, UUID=d0d2727a-1762-44cf-9924-2557a28913f1

Enabling swap:
sudo swapon /swap
