///////////////////Configure the Repositories of Package Manager /////////

>sudo vim /etc/apt/sources.list - to look this file in old Ubuntu version

in Ubuntu new versions(22)

>sudo vim /etc/apt/sources.list.d/ubuntu.sources

Why this is needed
When you add a software repository (like Docker’s) to Ubuntu, the system needs to verify that packages from that repository are authentic.

Ubuntu does this using GPG keys.

The GPG key is used to:
Verify that Docker packages are signed by Docker

Prevent tampering or fake packages

Allow apt to trust the repository


>curl "https://download.docker.com/linux/ubuntu.gpg -o docker.key

>ls -la - to see the key existing

>gpg --dearmor docker.key
>ls - and you will see docker.key.gpg been created

Now need to move the ly to apt package manager -where keeped third party keys:

>mv docker.key.gpg /etc/apt/keyrings

Need to add docker repo to the apt configuration

>ls /etc/apt - there we can create new source file for docker (source.list - is default apt file for repos)
but we want creale our new file with repo (keep it organized)

>sudo vim /etc/apt/source.list.d/docker.list

add there:
deb https://download.docker.com/linux/ubuntu noble stable

Means: 
Means:

“Ubuntu, please download stable Docker packages for Ubuntu 24.04 (noble) from the official Docker repository.”

And ti use with a key which we have exctracted before:

deb [signed-by=/ect/apt/keyrings/docker.key.gpg] https://download.docker.com/linux/ubuntu noble stable

Now we can save the file and run apt command:

>sudo apt update - which NOW will download the DOCKER !!! cause it has that config in the apt configiration!!

//////////////////////PPA ////////////
A Launchpad-hosted repository for Ubuntu .deb packages only.
personal package archive - when we want to use not vandors packages and not official.Or create our own repositories !!

A PPA is a custom APT repository hosted on Launchpad (a Canonical service).
It allows developers to distribute:

newer versions of software

experimental builds

software not included in Ubuntu

patched or customized versions 


>sudo add-apt-repository ppa:dani/mylatestapp
example> sudo add-apt-repository dani:graphic-drivers/ppa -  so it will create own repository belalf user and add to the apt file, and later others users can download it with apt manager


To list all ppa we have in the system:
>add-apt-repository --list

And remove ppa:
>sudo add-apt-repository --remove ppa:graphic-drivers/ppa

In rare cases, we may need to get packages that were available on an older Ubuntu distribution.

Configure the package manager with this extra repository:

deb http://us.archive.ubuntu.com/ubuntu/ focal main


This will make packages from Ubuntu 20.04 (codenamed Focal Fossa) available on this system.

Don't forget to also update APT's local cache

sudo vim /etc/apt/sources.list - in old ubuntu versions apt is using this file

added line:
deb http://us.archive.ubuntu.com/ubuntu/ focal main

Don't forget to also update APT's local cache:

sudo apt update
