The shell you specify must exist and be listed in /etc/shells.
If it’s not, login may fail.

for example:
/bin/bash
/bin/sh
/bin/zsh
/usr/bin/fish

When we want to add new shell:
Install Zsh: sudo apt install zsh
Install Fish: sudo apt install fish
Make sure it’s executable:sudo chmod +x /usr/local/bin/myshell
Step 2 — Add the shell to /etc/shells
sudo nano /etc/shells
/usr/bin/zsh
/usr/bin/fish
/usr/local/bin/myshell
Step 3 — Use the shell for a user
sudo adduser --shell /usr/bin/zsh dani
Or change an existing user’s shell:sudo chsh -s /usr/bin/zsh dani

How to verify the shell works: ls -l /usr/bin/zsh
Check that it’s in /etc/shells:cat /etc/shells
If both are correct, the user can log in normally.
