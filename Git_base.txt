////////////////Git Staging and Commiting Changes ///////


create a file
> touch dani.txt
>echo "some text" > dani.txt

Check the status of the file/files:
>git status

(we can see the file in Untracked files at the moment)

>git add dani.txt 

>git status - will show us this file now in the staging area .It is like you open your camera on the iphone and campture some object bu do not shoot the picture yet.


Unstage the file:
>git reset dani.txt 

More example:

To add only the files to staging which .html > git add "*.html"

To add subdirectory >git add Products/
or to add only .html files from Products >git add "Products/*.html"  REMEMBER always to use quotes when you uses asterisk in the characters
Remove multiple .html from the staging> git reset "Products/*.html"
