NICENESS - how process nice to another process in Linux
Can be Numbers can be from -20 to 19.Lower number is less niceness - LOWER NUMBER MEANS HIGHER PRIORITY !!!

For example both services running in the same time and we need to use all CPU which is available:
Process A has -20 - is higher priority and will leave less CPU for process B. A can use 95% of CPU
Process B has 19 - for example will get 5% of CPU only.

>nice -n -12 bash - will fail cann not set nice - Permission denied

so need root> sudo nice -n -12 bash 
and validate it was set> ps lax

SO:  nice - sets priority when starting a process
     renice - changes priority after it’s already running
	 

Permission rules:

Regular users can only increase their nice value (lower priority).

Only root can decrease nice value (raise priority).	

When to use:

A background job is hogging CPU and slowing your system → increase its nice value.

A critical job needs more CPU time → decrease its nice value (root only).

Managing long-running tasks on servers to keep the system responsive.

>renice 7 12345 - renice to 7 for PID=12345 
To make renice lower need root permissions> root renice 5 12345
